# Contributing to Code Repertoire

Thank you for your interest in contributing. Your interest and contributions help make this project successful. Questions and suggestions are welcome.

## Getting started

1. Read the README to understand the project's modules and supported framework.
2. Check the existing issues before starting new work.
3. For substantial changes, discuss your proposed approach in the relevant issue first.
4. Fork the repository and create a branch for your change.

## Development

- Follow the existing coding conventions unless a change has been agreed upon.
- Keep changes focused on one issue where practical.
- Add or update tests for changed behaviour.
- Do not introduce breaking changes without discussing them first.
- Please never commit passwords, API keys, connection strings containing secrets, or other credentials.

## Submitting changes

1. Build the solution and run the relevant tests.
2. Submit a pull request against the master branch.
3. Explain what changed, why it was needed, and how it was tested.
4. Address review feedback before requesting final approval.

All contributions are subject to maintainer review. Submission of a pull request does not guarantee acceptance.
